# Media Scraper

Media Scraper builds focused tools for authenticated media downloads and reliable local workflows on macOS.

Our main application is a native macOS desktop controller backed by a LaunchAgent. It manages authenticated downloads, local queue state, operational logs, and release workflows.

## What we care about

- Local-first processing and transparent state
- Reliable queue and worker lifecycle management
- Traceable logs and practical diagnostics
- Explicit confirmation before potentially disruptive file operations
- Small, focused tools that are easy to operate and maintain

## Project status

The project is under active development. The application and supporting tools are currently maintained in private repositories while we continue improving the runtime, packaging, documentation, and release process.
